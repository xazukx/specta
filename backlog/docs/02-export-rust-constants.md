# Export Rust Constants as TypeScript Constants

## Status: Not Currently Supported

Specta has no mechanism to export Rust constants (e.g., `const ALPHABET: &str = "abcdef"`) as TypeScript constants (e.g., `const ALPHABET = "abcdef"`).

### Background

Specta's type system is built around `DataType`, which represents **types** — structs, enums, tuples, primitives, etc. There is no `DataType` variant for constant values. A `DataType::Literal` variant existed previously but was removed in commit `b2e415e` (December 2025) because it was specifically for const generics and discriminated union tag values, not for exporting arbitrary constants.

The `#[derive(Type)]` macro works on type definitions (structs/enums), not on `const` or `static` items.

### Current Workarounds

There is no built-in workaround. The closest alternatives are:

1. **Unit-variant enums** — if your constants are a closed set of string values:
   ```rust
   #[derive(Type, Serialize)]
   enum Alphabet {
       A, B, C, D, E, F,
   }
   // Output: export type Alphabet = "A" | "B" | "C" | "D" | "E" | "F";
   ```

2. **Manual injection via `framework_runtime`** — you can inject arbitrary TypeScript into the output:
   ```rust
   use specta_typescript::{Exporter, Typescript};

   let exporter = Exporter::from(Typescript::default())
       .framework_runtime(|exporter| {
           Ok(format!(
               "export const ALPHABET = \"abcdef\";\n\n{}",
               exporter.render_types()?
           ).into())
       });
   ```
   This works but the constant values are hardcoded in Rust strings, not derived from Rust constants.

3. **Post-processing** — append constants to the generated file after export.

---

## Implementation Plan

### Design Overview

Add a way to register constant values with the `Types` collection and have the TypeScript exporter render them as `export const` declarations.

### Step 1: Add a ConstValue Type

Add a new data representation for constants in `specta/src/datatype.rs` or a new file `specta/src/datatype/constant.rs`:

```rust
/// A named constant value for export.
pub struct ConstValue {
    /// The constant's name (e.g., "ALPHABET")
    pub name: Cow<'static, str>,
    /// The TypeScript representation of the value (e.g., `"abcdef"` or `42`)
    pub value: ConstData,
    /// The type of the constant
    pub ty: DataType,
    /// Documentation comments
    pub docs: Cow<'static, str>,
}

pub enum ConstData {
    String(Cow<'static, str>),
    Integer(i64),
    Float(f64),
    Bool(bool),
    /// Raw TypeScript expression (for complex values like arrays/objects)
    Raw(Cow<'static, str>),
}
```

### Step 2: Add Registration API

Rather than a derive macro (which can't target `const` items), provide an imperative API:

```rust
use specta::Types;

const ALPHABET: &str = "abcdef";
const MAX_RETRIES: u32 = 3;

let mut types = Types::default();
types.register_const("ALPHABET", ALPHABET);
types.register_const("MAX_RETRIES", MAX_RETRIES);
```

This requires a trait for types that can be registered as constants:

```rust
pub trait ConstExport {
    fn const_data(&self) -> ConstData;
    fn const_type() -> DataType;
}

// Implement for common types
impl ConstExport for &str {
    fn const_data(&self) -> ConstData { ConstData::String((*self).into()) }
    fn const_type() -> DataType { DataType::Primitive(Primitive::str) }
}

impl ConstExport for i32 {
    fn const_data(&self) -> ConstData { ConstData::Integer(*self as i64) }
    fn const_type() -> DataType { DataType::Primitive(Primitive::i32) }
}
// ... etc for u32, f64, bool, String, etc.
```

### Step 3: Store Constants in Types/ResolvedTypes

Add a `constants: Vec<ConstValue>` field to the `Types` struct (or a parallel collection), and ensure it flows through to `ResolvedTypes`.

### Step 4: TypeScript Rendering

In `specta-typescript/src/primitives.rs` or `exporter.rs`, add constant rendering:

```rust
fn render_const(c: &ConstValue) -> String {
    let ts_value = match &c.value {
        ConstData::String(s) => format!("\"{}\"", s.replace('\\', "\\\\").replace('"', "\\\"")),
        ConstData::Integer(n) => n.to_string(),
        ConstData::Float(f) => f.to_string(),
        ConstData::Bool(b) => b.to_string(),
        ConstData::Raw(raw) => raw.to_string(),
    };
    format!("export const {} = {} as const;", c.name, ts_value)
}
```

### Step 5: Integration with Exporter

Modify the exporter's `export()` and `export_to()` methods to render constants alongside types. Constants would appear after the type declarations:

```typescript
// This file has been generated by Specta. Do not edit this file manually.

export type MyStruct = { name: string; age: number };

export const ALPHABET = "abcdef" as const;
export const MAX_RETRIES = 3 as const;
```

### Alternative: Macro-Based Approach

A proc macro could work on `const` items if designed as an attribute macro:

```rust
#[specta::constant]
pub const ALPHABET: &str = "abcdef";
```

This would be ergonomic but requires:
- A new proc macro in `specta-macros`
- Integration with the `collect` system (using `ctor` to register at startup)
- Careful handling of complex const expressions that can't be evaluated at macro time

The imperative API is simpler to implement and more flexible.

### Usage (After Implementation)

```rust
use specta::{Type, Types};
use specta_typescript::Typescript;

const ALPHABET: &str = "abcdef";
const MAX_RETRIES: u32 = 3;
const DEBUG: bool = false;

#[derive(Type)]
struct Config {
    name: String,
}

fn main() {
    let mut types = Types::default()
        .register::<Config>();

    types.register_const("ALPHABET", ALPHABET);
    types.register_const("MAX_RETRIES", MAX_RETRIES);
    types.register_const("DEBUG", DEBUG);

    let resolved = specta_serde::apply(types).unwrap();
    Typescript::default()
        .export_to("./bindings.ts", &resolved)
        .unwrap();
}
```

Output:
```typescript
// This file has been generated by Specta. Do not edit this file manually.

export type Config = { name: string };

export const ALPHABET = "abcdef" as const;
export const MAX_RETRIES = 3 as const;
export const DEBUG = false as const;
```
